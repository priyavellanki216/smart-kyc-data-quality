# Sample outputs

These CSV and XLSX files are generated from the fixed-seed synthetic portfolio and temporary SQLite state by `python scripts/build_sample_reports.py`. They contain only sample data, not production customer records. `detection_evaluation.json` is calculated from the generator's explicit seeded-defect truth labels and the actual validators/matcher. The XLSX workbook contains current example report sheets; regenerate it after intentional reporting-schema changes.
